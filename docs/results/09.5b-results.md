## What was built

- `uno/eval/aivat.py`: the estimator as a pure function of recorded games, made of these parts.
  - Value-model protocol: `StepRecord` / `ValueModel`.
  - Per-game correction sums: `GameTerms`, so any subset of corrections costs one subtraction.
  - `estimate_aivat`: per-seat estimates next to raw, the AIVAT − raw difference, and the pair (mirrored) estimate.
  - `stream_pairs`: plays pairs and keeps no traces.
  - Exhaustion rescoring of played games.
  - Bootstrap CIs.
  - `mirror_regret`: section 21's sampled edge decomposition, now read off the same records (`sampled_mirror` uses it).
- `uno/compiled/aivat.py`: the exact side.
  - Exact moments of the estimator in one backward pass (`aivat_moments`).
  - Value-function families: exact, noisy per L2 set, L1-set averages, other profiles, a fitted critic.
  - Exact outcome R².
  - `TreeValues`: tree values for played games, through `NodeIndex.arcs`.
- `uno/game/chance.py`: `draw_outcomes`, the chance model of any ruleset. It covers seeded reshuffles and
  ticket draws (the open item of `context.md` section 9). A penalty draw that crosses a reshuffle
  gets no model; its corrections are skipped.
- `uno/eval/critic.py`: a colour-symmetric feature critic.
  - Fractional logistic fitted by chunked IRLS, numpy only.
  - Fitted on the new `FIT_SEEDS` (10,000,000+).
  - `CriticValues`: its value model.
- `uno/game/rules.py`: the intermediate rulesets `MID_12` and `MID_25`.
- `uno/experiments/aivat.py` (toys) and `uno/experiments/aivat_uno.py` (sweep, intermediates, full UNO, transfer curve).
- Tests: `tests/eval/test_aivat.py`, `tests/eval/test_critic.py`, `tests/game/test_draw_outcomes.py`.

**A design correction from planning.** The brainstorm called the full-UNO value function an "L3
critic". AIVAT integrates V over each draw under the distribution V conditions on. A V that reads the
pile order makes every draw deterministic, which leaves only the deal and reshuffle permutations as
chance events, and their expectations are intractable. So V is an **L2-state** value: both hands, the
public history, the pile as a multiset. On the toys that is exactly the lazy tree's node value. The same
applies to D5 of the brainstorm: the potential that coincides with AIVAT's deal correction is the L2
value of the deal, not the L3 one.

## 1. Correctness on the toys (`uv run uno aivat`)

Matchups: heuristic vs random, BR L1(random) vs random, nash vs random, nash vs heuristic, the row at both
seats.

**Deterministic identities, all pass on every toy.**

- Constant V reproduces raw on every game.
- Exact V with every correction gives the root value on every game, with a largest deviation of
  5.1e-16 over all games of all toys. That holds for pile and ticket draws and for the three scorings of exhaustion.
- The exact mean equals the profile's value for every correction subset, and the variance is zero with
  every correction.

**Sampled against exact** (4000 EVAL pairs). Each sampled mean is checked against the exact whole-game
value with z on AIVAT's own standard error; each variance must fall inside a 99.8 % bootstrap CI around the
exact variance. The AIVAT − raw difference has mean zero, and raw means match under each scoring. There are
223 stochastic checks per toy (1,115 over the five, the deal-term checks of this section included): **1 miss**. TOY2_SKIP, ticket draws, heuristic vs
random, seat 1 variance: 0.06484 exact against a CI starting at 0.06494.

The miss was rechecked on ten fresh ranges (five pile, five tickets, 4000 pairs each). The exact variance
was inside every CI, and pooled over 20,000 games the variance is 0.06473 against 0.06484. Chance
(`logs/step9.5b/recheck_TOY2_SKIP_tickets.log`).

**The deal model, 7x tighter than step 9.5a.** AIVAT's deal term `nu(first state) - E_model nu` needs no
play, only a lookup per seed, so millions of seeds take seconds. Five disjoint ranges of 1,000,000 seeds
were run per toy, for three profiles (heuristic vs random, random vs heuristic, random vs random). Pooled
over 5,000,000 seeds every |z| is below 1: TOY −0.48 / −0.39 / −0.24, TOY2 −0.21 / −0.69 / −0.63,
TOY2_SKIP −0.81 / +0.76 / −0.10, DUPS +0.93 / −0.10 / +0.90. That is 3σ ≈ 0.04 score points on TOY,
against ≈ 0.24 at 100,000 seeds in step 9.5a.

The check was prompted by a first 200,000-seed range (7,000,000+) where all 12 terms came out positive,
up to z +2.81 on TOY. The disjoint ranges show that was the range's own deal luck: the per-range means
change sign (`logs/step9.5b/deal_term_*.log`). The check is now section 0 of `uno aivat`.

## 3. Value-function quality (the imperfect-V curve)

Outcome R² over visited decisions against the exact variance ratio, every correction on (with deal) and
without the deal correction (what full UNO has). Excerpt, heuristic vs random, seat 0 / seat 1:

| ruleset | value function | R² | ratio, with deal | ratio, no deal |
|---|---|---|---|---|
| `TOY` | exact | 0.73 / 0.78 | 0 / 0 | 0.42 / 0.49 |
| | exact + noise σ 0.05 | 0.72 / 0.78 | 0.007 / 0.005 | 0.43 / 0.49 |
| | exact + noise σ 0.1 | 0.71 / 0.77 | 0.03 / 0.02 | 0.44 / 0.50 |
| | L1-set values | 0.61 / 0.57 | 0.35 / 0.57 | 0.63 / 0.75 |
| | random vs random's values | 0.66 / 0.62 | 0.17 / 0.35 | 0.47 / 0.59 |
| | fitted critic (20,000 games) | 0.50 / 0.44 | 0.46 / 0.68 | 0.74 / 0.88 |
| `TOY2_FULL` | exact | 0.66 / 0.70 | 0 / 0 | 0.39 / 0.41 |
| | L1-set values | 0.50 / 0.47 | 0.40 / 0.56 | 0.61 / 0.69 |
| | random vs random's values | 0.60 / 0.58 | 0.18 / 0.27 | 0.44 / 0.51 |

Readings:

1. **Small errors in V cost little** (noise σ = 0.05 return units: ratio 0 → 0.007); AIVAT degrades
   smoothly.
2. **R² orders value functions only roughly.** Another profile's exact values (R² 0.66) beat the
   L1-set values (R² 0.61) by a factor of two in variance. What matters is getting the *changes* at
   chance events right, which outcome R² measures only indirectly.
3. **The L1-set values are what an L1 critic could at best learn**, and they already lose half of the
   gain. This is one more reason to give the critic both hands (L2).
4. **The fitted critic's played path matches the tree**: `CriticValues` through `draw_outcomes` against
   `critic_values` on the tree, sampled mean and variance inside the exact references on every toy
   (section 4 of the logs). Without the deal correction a toy critic removes only 2-26 %, because on the
   toys the deal is most of the luck.

## 4. The intermediate rulesets (`uv run uno aivat_uno sweep`)

Pre-declared rule (spec section 23). The candidates are 17 scaled-down full-UNO decks, measured over 1,000
DEV pairs of Heuristic vs Random. A candidate qualifies if its game length is within ±20 % of 12 or 25
actions and its four decision shares are each within 0.5-2x of FULL_UNO's. Among qualifiers, the one with
the smallest largest |log share ratio| wins.

The first round of 10 candidates had none for 12 actions: every short deck held too many wilds per card,
a "wild: hold or spend" share 2.3-2.6x full UNO's. A second round of 7 candidates with fewer wilds was added
with the rule unchanged. The pick at 25 then moved from `c4 r1222 s1 r1 d1 w2 f2 h5` (round 1) to a
round-2 candidate that scores closer.

## 5. AIVAT on full UNO and the transfer curve (`uv run uno aivat_uno`)

A critic per profile is fitted on 10,000 FIT_SEEDS games, then AIVAT runs on 4000 EVAL pairs, streamed.
Corrections: chance and both players' actions, no deal correction. Score of the row:

| ruleset | matchup | seat | decisions / game | critic R² | var ratio [95 % CI] | deals for 3 pts at 3σ, 80 % power: raw → AIVAT |
|---|---|---|---|---|---|---|

| `MID_25` | heuristic vs random | 0 / 1 | 21.7 | 0.16 / 0.18 | 0.734 / 0.719 | see log |
| `FULL_UNO` | heuristic vs random | 0 | 45.2 | 0.110 | 0.714 [0.689, 0.740] | 3,860 → 2,757 |

Transfer curve, heuristic vs random, same corrections:

| ruleset | decisions / game | critic R² | var ratio (sampled) | exact ratio of that critic | exact values, no deal |
|---|---|---|---|---|---|
| `TOY` | 6.2 | 0.50 / 0.44 | 0.73 / 0.88 | 0.74 / 0.88 | 0.42 / 0.49 |
| `TOY2` | 6.8 | 0.39 / 0.33 | 0.77 / 0.87 | 0.79 / 0.86 | 0.39 / 0.41 |
| `TOY2_SKIP` | 6.6 | 0.36 / 0.33 | 0.78 / 0.83 | 0.79 / 0.84 | 0.46 / 0.42 |
| `MID_12` | 14.0 | 0.24 / 0.25 | 0.76 / 0.75 | | |
| `MID_25` | 21.7 | 0.16 / 0.18 | 0.73 / 0.72 | | |
| `FULL_UNO` | 45.2 | 0.11 / 0.11 | 0.71 / 0.76 | | |

Readings:

1. **AIVAT with a plain logistic critic removes 24-29 % of full UNO's variance**, about 1,000 deals of the
   ~3,900 needed for a 3-point difference at 3σ with 80 % power. Mirroring removes ~10 % there, and
   pairing between dissimilar policies ~11 % (steps 8.5 and 9). AIVAT is the first estimator that helps
   between dissimilar policies on full UNO. It can be combined with mirroring (the log has the pair
   variance of the AIVAT scores), but that combined gain was not measured against raw mirroring here.
2. **The ratio stays at 0.72-0.76 from 14 to 45 decisions (0.73-0.88 for the toys' critics) while the
   critic's R² falls from ~0.45 to 0.11.** Longer
   games have more chance events, so a weaker per-state value still collects comparable variance. The
   toys only matched it through the deal correction, which full UNO lacks. The toy prediction (critic
   quality → variance ratio) therefore does not transfer by R²: it is the number of corrected events
   that carries the gain.
3. **The critic is the obvious lever.** On the toys, exact values without the deal correction reach
   0.39-0.49 against the critic's 0.73-0.88. A better full-UNO V (more features, a network, or a PIMC value
   in 9.5c) has up to twice the gain to collect; how much of it transfers to 45-decision games is unmeasured.
4. **Cost**: 26-38 ms per full-UNO game, ~20x plain play, on top of a 40-50 s critic fit per profile. The
   chance model skips 0.004-0.009 % of the decisions on full UNO (penalty draws across a reshuffle) and
   0.08-0.33 % on the intermediates.

## 6. Failed checks

`uno aivat_uno`: 7 failed checks of 288 stochastic ones, ~0.8 expected. They are two distinct events,
each counted several times:

- **TOY2, heuristic vs random, seat 1, chance corrections, AIVAT − raw z −3.28** (and its voluntary-draw
  component). `heuristic_t1` on TOY2 has no action cards, so it plays the same games and repeats the
  failure. On a toy the critic's played path is identical to the exact tree record by record
  (`tests/eval/test_critic.py`) and the chance model is the exact one, so this one cannot be a
  chance-model bias.
- **FULL_UNO, heuristic vs random, seat 0, AIVAT − raw z −3.08 / −3.06 / −3.08** (the three correction
  subsets, one quantity). The critic's voluntary-draw corrections lean positive on full UNO in every
  matchup and seat.

**Investigated: chance, not a chance-model bias.**

1. *Fresh seeds* (30,000,000+, 8,000 games of Heuristic against Random, seat 0): per-game chance corrections
   with the fitted critic have z +1.02 over all events (voluntary draws +1.28), and with a simple fixed V
   z +0.50 (`logs/step9.5b/full_uno_chance_check.log`).
2. *Drawn-card uniformity* (no value function): at every draw, playable / wild / number / current-colour
   indicators and a randomised PIT over card types, against `draw_outcomes`' distribution.
   - A first version played each seed at both seatings, and those two games draw from one pile order.
     Its z-scores were inflated, which flagged the TOY2 control (z −3.67) and MID_25 (z +3.07).
   - Rerun with one game per seed and z on per-game sums (TOY2 and MID_25 200,000 games, FULL_UNO
     40,000; about 1.7 million draws): the largest |z| over 44 statistics is 2.21, and every PIT is within
     |z| 1.4, reshuffle draws included (`logs/step9.5b/draw_uniformity_independent.log`).

So the chance model is right on full UNO and the intermediates. The FULL_UNO miss is one quantity measured
three times on the EVAL range, and the TOY2 miss is on a ruleset whose model is exact.

Two lessons. Several checks of one run share its games (the three matchups share seeds and near-identical
play), so "~0.8 expected" understates how often a correlated family misses. And any draw-level test must
not use both seatings of one seed as independent draws.
