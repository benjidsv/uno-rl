> `pilot 5000`, `aivat 4000 20000 2`, `mc 200 16`. Logs: `logs/step9.5c/`.
> Tests: `uv run pytest` (154 passed, 6 min 44 s; the 9 new PIMC / value-network tests add ~30 s).
> Plan: [plan.md](../plan.md) row 9.5c. Spec: [spec.md](../spec.md) section 24.
> The PIMC *agent* (exact PIMC-∞ on the toy world trees, PIMC-n, the full-UNO search row, D2 with a
> search Q) is step 9.5d: this step is the value function.

## Why the step turned out this way

Step 9.5b left "a better V has up to twice the gain to collect" as the open item, with the full-UNO
critic at a variance ratio of 0.71-0.76. Two facts, both measured during planning, set the design:

1. **The ceiling is much lower than 0.7.** With exact L2 values and corrections at chance and both
   players, AIVAT's estimate is exactly the value of the dealt hands, so its residual variance is the
   deal's. On full UNO that share is **0.086 / 0.090** (section 2), not 0.4 as on the toys.
2. **Rollouts cannot be the V.** A V made of rollouts of the played profile makes the corrections
   telescope towards "n more games from the same hands", at the cost of those n games, and its
   independent noise adds about `2 (1 - V²) / n` per decision. Section 5 measures it: on full UNO at
   16 rollouts per value the ratio is 3.4-4.0, i.e. worse than applying no corrections at all.

So PIMC rollouts are the **teacher**: they value states off-line, a network is fitted on those values,
and the network is AIVAT's V at the critic's cost.

## What was built

- `uno/eval/pimc.py`: determinization at L2 (uniform order of the unknown pile, fresh seed, pile
  draws), `rollout` / `rollout_value` / `rollout_q`, `RolloutValues` (rollouts as a value model, for
  the cost measurement), `deal_floor`, `teacher_targets` (on-path states plus the siblings AIVAT
  values), and a process pool.
- `uno/eval/value_net.py`: colour- and rank-symmetric features (one block per colour plus a global
  block), a DeepSets network over the colour blocks, float64 CPU inference, the fit, save / load.
- `uno/eval/play.py`: `DEAL_SEEDS` (40,000,000+) for the deal mean where no tree exists.
- `uno/eval/critic.py`, `uno/compiled/aivat.py`: the value-model interface (`features`,
  `observation_features`, `values`) is now shared by the critic and the network, so `CriticValues` and
  `critic_values` take either.
- `uno/experiments/aivat_uno.py`: `run_matchup` split into `fit_critics` / `toy_values` /
  `evaluate_matchup`, so 9.5c reuses every 9.5b check.
- `uno/experiments/pimc_value.py` (`check`, `floor`, `pilot`, `aivat`, `mc`).
- Tests: `tests/eval/test_pimc.py`, `tests/eval/test_value_net.py`.

## 1. The rollout values are the exact L2 values (`uv run uno pimc_value check`)

400 decisions of EVAL games per cell, 400 rollouts per value, against the exact node value and arc
expectation of the tree: TOY, TOY2_SKIP and DUPS, pile and ticket draws, heuristic vs random at both
seats. **48 checks, 0 failures.** Every pooled z is within ±1.9 and every mean z² within its band; the
decisions whose outcome is already certain match the exact value to 1e-12 (230-291 of 400 per cell on
these toys).

That covers the parts `draw_outcomes` does not model: ticket draws, duplicate cards, +2 / +4 penalty
draws. The determinization is also tested to be independent of the real pile order and seed
(`tests/eval/test_pimc.py`), which is what keeps AIVAT unbiased.

## 2. The deal floor: what any L2 value function can reach (`uv run uno pimc_value floor`)

2,000 EVAL deals, each replayed under 32 determinizations of the pile. The share is the variance ratio
AIVAT reaches with exact values and every correction but the deal's.

| ruleset | matchup | seat 0 / seat 1 share [95 % CI] | exact | deals for 3 pts, raw → exact V |
|---|---|---|---|---|
| `TOY` | heuristic vs random | 0.419 / 0.474 | 0.424 / 0.487 | 2,736 → 1,145 / 3,715 → 1,762 |
| `TOY2` | heuristic vs random | 0.382 / 0.402 | 0.387 / 0.413 | 3,501 → 1,336 / 3,918 → 1,575 |
| `TOY2_SKIP` | heuristic vs random | 0.460 / 0.403 | 0.461 / 0.423 | 3,570 → 1,641 / 3,950 → 1,591 |
| `MID_12` | heuristic vs random | 0.247 / 0.256 | | 3,923 → 968 / 4,096 → 1,048 |
| `MID_25` | heuristic vs random | 0.173 / 0.163 | | 3,970 → 687 / 4,073 → 663 |
| `FULL_UNO` | heuristic vs random | **0.086 / 0.090** | | 3,878 → 334 / 3,944 → 353 |
| `MID_12` | heuristic vs heuristic_col | 0.370 | | 4,072 → 1,505 |
| `MID_25` | heuristic vs heuristic_col | 0.241 | | 4,090 → 985 |
| `FULL_UNO` | heuristic vs heuristic_col | 0.169 | | 4,098 → 694 |

Readings:

1. **The longer the game, the less the deal decides**: 0.39-0.46 on the toys, 0.25 at 14 decisions,
   0.17 at 22, 0.086-0.090 at 45. This is the mirror image of 9.5b's finding that the number of
   corrected events carries AIVAT's gain.
2. **An exact L2 V would need ~350 deals instead of ~3,900** for a 3-point difference at 3σ with 80 %
   power against Random: 11x. Against a near-identical column (heuristic_col) the floor is twice as
   high: two near-identical policies diverge late, so their games share more and the deal decides more
   of the difference.
3. The toy shares agree with the exact ratios. All six came out slightly below, which is the EVAL
   range's own deal luck, not the estimator: on the same seeds the rollout estimate of the
   between-deal variance matches the exact one (0.279 vs 0.285, 0.430 vs 0.428, 0.326 vs 0.322, 0.384
   vs 0.380).

## 3. Teacher and student: how to spend the rollouts (`uv run uno pimc_value pilot`)

FULL_UNO, heuristic vs random, seat 0, at a fixed budget of 40,000 game-rollouts, against 20,339 DEV
states valued with 128 rollouts each (target noise 0.0063, variance 0.180):

| rollouts per state | games | states | teacher | R² vs the true values | outcome R² |
|---|---|---|---|---|---|
| 2 | 20,000 | 1,482,037 | 205 s | **0.840** | 0.179 |
| 8 | 5,000 | 369,119 | 197 s | 0.825 | 0.176 |
| 32 | 1,250 | 93,475 | 204 s | 0.785 | 0.165 |

Readings:

1. **Many noisy targets beat few clean ones.** At a fixed budget, n = 2 on 20,000 games wins: the
   fit averages the noise away, and the extra states cover more of the space.
2. **Width does not matter** (64 / 128 / 256 are within noise of each other at every n), so the limit
   is the features, not capacity. 128 is used.
3. The network explains **84 % of the variance of the true L2 values**, and its outcome R² (0.18)
   already beats the critic's 0.11 — these are DEV states, and section 4 reports 0.148 against 0.110
   over the EVAL games — though 9.5b showed outcome R² orders value functions only roughly.

## 4. AIVAT with the network (`uv run uno pimc_value aivat`)

4,000 EVAL pairs, the **same games** for both value functions (checked per seat: the raw scores are
identical arrays). The critic is 9.5b's, fitted on 10,000 FIT games; the network is fitted on the
rollout targets of 20,000 FIT games at 2 rollouts per state. Corrections as in 9.5b, plus `+deal`:
the exact deal mean on the toys, the Monte Carlo mean over 250,000 `DEAL_SEEDS` deals elsewhere.

Variance ratio AIVAT / raw, heuristic vs random, seat 0 / seat 1:

| ruleset | decisions | critic | critic +deal | network | network +deal | floor (section 2) |
|---|---|---|---|---|---|---|
| `TOY` | 6.0 / 6.3 | 0.732 / 0.876 | 0.463 / 0.681 | 0.446 / 0.514 | **0.043 / 0.055** | 0.424 / 0.487 |
| `TOY2` | 6.7 / 6.8 | 0.769 / 0.870 | 0.606 / 0.775 | 0.461 / 0.526 | 0.133 / 0.183 | 0.387 / 0.413 |
| `TOY2_SKIP` | 6.5 / 6.6 | 0.784 / 0.827 | 0.592 / 0.640 | 0.525 / 0.519 | 0.148 / 0.168 | 0.461 / 0.423 |
| `MID_12` | 14.0 / 14.1 | 0.755 / 0.751 | 0.599 / 0.598 | 0.531 / 0.537 | 0.327 / 0.347 | 0.247 / 0.256 |
| `MID_25` | 21.6 / 21.8 | 0.734 / 0.719 | 0.637 / 0.617 | 0.510 / 0.499 | 0.378 / 0.368 | 0.173 / 0.163 |
| `FULL_UNO` | 45.2 | 0.714 / 0.757 | 0.657 / 0.697 | **0.460 / 0.469** | 0.384 / 0.394 | 0.086 / 0.090 |

The other two full-UNO matchups: heuristic_t1 vs random 0.450 / 0.482 (critic 0.735 / 0.757),
heuristic vs heuristic_col 0.508 / 0.518 (critic 0.754 / 0.718).

**The pre-declared criterion passes at both seats.** Network 0.460 [0.439, 0.482] and 0.469
[0.448, 0.491] against critic 0.714 [0.689, 0.740] and 0.757 [0.729, 0.787]: the CIs are disjoint and
both point values are under 0.5. Deals for a 3-point difference at 3σ with 80 % power on full UNO:

| | seat 0 | seat 1 |
|---|---|---|
| raw | 3,860 | 3,956 |
| AIVAT, critic | 2,757 | 2,996 |
| AIVAT, network | **1,776** | **1,854** |
| AIVAT, network + deal | 1,483 | 1,558 |

Readings:

1. **The critic reproduces 9.5b digit for digit** (0.714 / 0.757, deals 2,757 / 2,996): the shared
   value-model interface, the split of `run_matchup` and the parallel evaluation changed nothing.
2. **The network's ratio is flat at 0.45-0.53 from 6 to 45 decisions while the floor falls**, so the
   share of the *reducible* variance it captures, `(1 - ratio) / (1 - floor)`, falls with game length:
   96 % on `TOY`, 87-88 % on the other toys, 62 % on `MID_12`, 59 % on `MID_25` and `FULL_UNO`. The
   critic's flat 0.72-0.76 (9.5b) and the network's flat ~0.5 are the same phenomenon one level up:
   both the gain and the residual scale with the number of corrected events.
3. **What a fitted V is short of is local accuracy, not fit.** Its R² against the true values is
   0.83-0.84 on full UNO, the same as on the intermediates and far above the outcome R² (0.148 against
   the critic's 0.110). AIVAT only ever sees the *change* of V across a chance event, so a smooth error
   cancels in the telescoping and only the one-step error survives. Outcome R² remains a rough
   ordering at best (9.5b's lesson, now with a four-fold larger sample of value functions).
4. **The deal correction is now available where no tree exists** and is worth another 8-15 points of
   ratio on full UNO and the intermediates. Its Monte Carlo mean carries a fixed error (0.04-0.05 score
   points at 250,000 deals) that does **not** shrink with more evaluated games, and two agents fitted
   with different value functions carry different such constants: usable for a matchup value, to be
   avoided for a small paired difference between two rows.
5. **On the toys the network is nearly the exact value function**: with every correction 0.024-0.055
   on `TOY` (the exact V gives 0), 0.11-0.18 on the three-rank toys. Its sampled moments sit on its own
   exact tree moments (mean z within ±1.6, variances inside the 99.8 % CIs, sampled ratio 0.446 against
   exact 0.451), which is the played path and the tree path agreeing for a fitted model.
6. **Failed checks: 7 of 648** (~1.7 expected), every one of them the critic's, and both are 9.5b's
   known events reproduced to the digit: TOY2 seat 1 chance corrections z −3.28 (counted twice because
   `heuristic_t1` has no action cards on TOY2 and plays identical games) and FULL_UNO seat 0 z −3.08 /
   −3.06 / −3.08 (one quantity in three subsets). **No network check failed**, and the network's
   counterpart of the full-UNO miss is z −2.52.
7. **Cost.** Per full-UNO game, wall clock on 8 cores: 6.8 ms with the critic, 9.9 ms with the network
   (the evaluation is now parallel, so CPU time per game is about eight times that; 9.5b measured
   26-38 ms single-core). Fitting a profile costs 47 s for a critic against 768 s for the network
   (teacher rollouts plus training), paid once per profile. The chance model still skips
   0.004-0.009 % of full-UNO decisions.

## 5. Rollouts used directly as V: the cost (`uv run uno pimc_value mc`)

**On the toy, rollout values converge to the floor.** `RolloutValues` with n rollouts per value, TOY
heuristic vs random, 200 EVAL pairs, chance + both players: the mean is right at every n (|z| ≤ 0.5)
and the variance ratio falls towards the exact-value floor as the noise dies:

| rollouts per value | ratio seat 0 | exact values |
|---|---|---|
| 4 | 0.980 | 0.424 |
| 16 | 0.510 | 0.424 |
| 64 | 0.429 | 0.424 |

That is the design argument made visible: a rollout V is unbiased and, given enough rollouts, as good
as the exact value function — at n rollouts per value per decision.

**On full UNO it is a losing trade**, 200 EVAL pairs, cost as one-core CPU-seconds for a 3-point
difference at 3σ with 80 % power (deals needed × seconds per pair):

| V | ms per pair | ratio (seat 0 / 1) | deals | CPU-seconds |
|---|---|---|---|---|
| raw (no corrections) | 2.6 | 1.000 | 4,027 / 3,644 | **10.4 / 9.4** |
| critic | 73.5 | 0.690 / 0.724 | 2,779 / 2,638 | 204 / 194 |
| network | 94.6 | 0.366 / 0.551 | 1,474 / 2,007 | 139 / 190 |
| rollouts, n = 16 | 2,555 | 3.989 / 3.421 | 16,066 / 12,466 | 41,055 / 31,856 |

(The ratios here are noisier than section 4's: 200 pairs, not 4,000.)

Readings:

1. **Rollouts as V are worse than no V at all** on full UNO at 16 rollouts per value: ratio 3.4-4.0,
   because the independent noise of ~90 values per game swamps what the corrections remove. The opening
   section's arithmetic (~2(1 − V²)/n per decision) predicted it; this is it, measured.
2. **AIVAT does not pay in CPU-seconds when the agents are cheap.** A rulebot pair costs 2.6 ms; the
   corrections cost 30-90 ms. Playing 4,000 more deals is an order of magnitude cheaper than removing
   half the variance from 4,000. AIVAT's gain is in *deals*, so it pays exactly when a deal is
   expensive or scarce: a search agent (9.5d's PIMC row, ~1-2 s per game, where the corrections are
   5 % of the cost), a large network, a fixed pool of recorded games, or a wall-clock-bound ladder run.
3. This does not weaken section 4: the deliverable is 1,776 deals instead of 3,860 for the same
   resolution. It fixes *when* to spend it.
