## What was built

- `uno/eval/search.py`: `response_value` -- each determinized world solved as a perfect-information
  **best response to the opponent's real policy** (expectimax at the opponent's nodes) instead of
  two-sided minimax, which is the `"response"` continuation `uno/compiled/pimc.py` measures exactly
  on the toys. `PimcSearch(opponent=...)` selects it.
- `leaf_for` and per-seat leaves: step 9.5d handed the agent the **seat-0** value network at both
  seats. One agent object plays both seatings of a deal, so this is not a one-line `nets[seat]`
  change as that step's note assumed -- the leaf has to be chosen from `obs.seat` inside the agent.
- `uno/experiments/pimc.py`: per-seat nets throughout, `s32x2r` sweep tokens, a paired
  response-versus-two-sided table, and `uv run uno pimc uno ... r`.
- Tests: 6 new functions, 10 cases with parametrisation, in `tests/eval/test_search.py` (22 in the
  file, up from 12).

## 1. The continuation rule (`uv run uno pimc sweep 1000 "" "s32x2,s32x2r,heu"`)

Raw score against Random, 1,000 EVAL deals per config, both seatings. **0 failed checks.**

| row | seat 0 | seat 1 | ms/game (wall clock, 8 cores) |
|---|---|---|---|
| PimcSearch w=32 d=2 (two-sided) | 0.6640 +- 0.0149 | 0.6660 +- 0.0149 | 188.9 |
| **PimcSearch w=32 d=2 response** | **0.7660 +- 0.0134** | **0.7180 +- 0.0142** | **128.7** |
| Heuristic | 0.6190 +- 0.0154 | 0.6080 +- 0.0154 | 1.1 |

(These are wall-clock per game over 8 workers, as the tool prints them; step 9.5d's cost tables
quote *one-core* figures measured separately, so the two are not comparable. The comparison within
this table is, since the configs ran back to back on one machine.)

Paired, response minus two-sided: **+10.20 +- 1.79 (z +5.7)** at seat 0, **+5.20 +- 1.80 (z +2.9)**
at seat 1.

Readings:

1. **The continuation rule is the largest lever found on full UNO so far**, and it is the one the
   exact toys pointed at (up to 8.8 points there, worst on free play, which full UNO is). At seat 0
   it clears this project's 3-sigma bar comfortably; at seat 1, z +2.9 does not, so at this sample
   size the claim was "established at seat 0, indicated at seat 1". **Section 3 settles seat 1**: at
   3,000 deals the same comparison is +4.57 +- 1.06 (z +4.3), so the lever is established at both.
   The toys predicted the sign and roughly the size at both.
2. **Responding is *cheaper* than assuming a clairvoyant opponent** -- 128.7 against 188.9 ms per
   game -- which contradicts the prediction made when this step was scoped ("expectimax drops
   alpha-beta, so expect 2-4x slower"). The mechanism: expectimax expands only the actions in the
   opponent's *support*, and both rulebots are far from uniform (Random never draws with a play in
   hand; the Heuristic is frequently a point mass), so the branching factor at opponent nodes
   collapses by more than pruning was buying. A better continuation rule is therefore free.
3. **The seat asymmetry is gone.** Two-sided PIMC now scores 0.6640 / 0.6660 where step 9.5d's
   sweep had 0.6950 / 0.5600 at the same budget. Seat 0 is unchanged within noise (-3.1 +- ~3.8);
   seat 1 is +10.6, about 2.8 sigma against that step's own 200-deal figure. That is the direction
   9.5d predicted for the per-seat network fix, but it is a comparison *across runs* at different
   sample sizes, not a paired test, so it is evidence and not proof.
4. **PIMC now beats the rulebot at both seats**, which it did not in 9.5d (it lost seat 1, 0.5633
   against 0.6433). The response row is +14.7 / +11.0 points on the Heuristic.
5. **Sanity on the unchanged row**: the Heuristic's 1,000-deal seat mean here is 0.6135, against
   the ~0.603 on record from [step 8.5](../03-08-foundations/08.5-transfer.md); its apparent movement from 9.5d's
   200-deal 0.5750 / 0.6700 is -6.2 / +4.4 points, both inside that run's ~3.5-point standard
   error. 9.5d's own warning that its 200-deal sections were power-limited is visible here.

**What the response row is, and is not.** It best-responds inside each world to the column's
*known* policy, so it is a different policy per column (and carries a different name, since a name
identifies a policy). That is legitimate for every ladder cell -- the columns are Random, the
Heuristic, and later a tabulated checkpoint -- but it is **not** a general player, and on the toys
fitting the belief to one opponent *costs* exploitability. The opponent is also assumed memoryless:
its policy is evaluated on its L1 observation inside a determinized world whose fabricated history
for that seat never happened, which is exact for the rulebots and wrong for a memoryful column.

Readings:

1. **Head to head the response row now beats the rulebot at both seats** (0.6180 / 0.6010). Step
   9.5d's two-sided row lost both (0.5133 / 0.4633). Against Random the two rows are 0.7660 / 0.7180
   against 0.6190 / 0.6080.
2. **The raw scores reproduce section 1 to the digit** (0.7660 / 0.7180) -- two independent runs over
   the same seeds with a deterministic agent, which is the cross-check that says the sweep and the
   AIVAT path play the same policy.
3. **The row correction is identically zero on both PIMC rows** (`action row +0.0000` at every seat
   and matchup), so 9.5d's consequence of keyed world sampling survives the new continuation: all of
   AIVAT's gain comes from chance and the opponent. The Heuristic row remains the contrast, the only
   row with a non-zero own-action term.
4. **AIVAT works less well on a search row than on the rulebot**, as in 9.5d: 0.60-0.68 against the
   Heuristic row's 0.437 / 0.493. The cause is unchanged -- the network is off-profile for these
   games (R^2 0.07-0.25) -- and it is now the largest remaining lever (section 6, item 2).
5. **Unbiasedness holds throughout**: every AIVAT - raw z is inside +-3 (largest -1.96), and every
   zero-mean correction term checks out, over 0 failed checks for the run.
6. **The response row is also the cheapest PIMC row measured**, at 78.9-142.5 ms/game against the
   rollout player's 154.6-191.1, and it plays *shorter* games (33.7-37.9 decisions against 48.4-57.7,
   the Heuristic's 46.0): a stronger player ends them sooner, which compounds the speed advantage
   already seen in section 1.

| **128** | **0.7677 +- 0.0077** | **0.7403 +- 0.0080** | 530.0 | +6.67 +- 0.99 (z +6.7) / +5.70 +- 1.00 (z +5.7) |
| 256 | 0.7660 +- 0.0077 | 0.7347 +- 0.0081 | 1060.2 | +6.50 +- 1.00 (z +6.5) / +5.13 +- 1.00 (z +5.1) |
| Heuristic | 0.6163 +- 0.0089 | 0.6037 +- 0.0089 | 0.5 | |

**The ladder climbs to 32 and then flattens.** Against w = 32 the point estimates are +0.06 / +1.77
at w = 64, +1.10 / +2.37 at w = 128 and +0.93 / +1.80 at w = 256 -- and 256 comes out *below* 128 at
both seats. Unpaired, w = 128 minus w = 32 is ~+1.1 points at z ~ 1.0, so nothing past 32 approaches
3 sigma even at this sample size.

*A limitation of this table, since fixed.* Every paired row shares w = 8 as its base, so the standard
error of a difference *between* two of them is not recoverable from what is printed (the rows are
correlated). That is why the "past 32" reading above falls back on unpaired errors. The sweep now
also prints each doubling against the previous one, which is the comparison this question actually
wants.

**This refutes the hypothesis recorded as section 6, item 3.** Step 9.5d attributed the flattening
to its own approximations -- the seat-0 network at both seats and the two-sided continuation. Both
are now fixed, the ladder reaches double that step's top, and the power is 15x; it still flattens.
So the flattening is a property of the method as it stands, not of the wiring, which *strengthens*
9.5d's other explanation: more samples of a position that is evaluated badly buy nothing. **The leaf
value function, not the world budget, is the binding constraint.**

### Depth, at 32 worlds

| depth | seat 0 | seat 1 | ms/game | paired vs d=2, seat 0 / seat 1 |
|---|---|---|---|---|
| 2 | 0.7567 +- 0.0078 | 0.7167 +- 0.0082 | 131.3 | -- |
| 3 | 0.7563 +- 0.0078 | 0.7073 +- 0.0083 | 482.3 | -0.03 +- 0.89 (z -0.0) / -0.93 +- 0.89 (z -1.1) |

**Depth does nothing, and now that is measured rather than suspected.** All four differences sit
within 1.5 sigma of zero, and the intervals exclude gains above ~2.7 points at 3 sigma, for 3.7x
(d = 3) and 13.5x (d = 4) the cost. Step 9.5d could only say "dominated, harm unproven" off
differences of about one standard error at 200 deals; at 3,000 the honest statement is **no effect
in either direction, at four to thirteen times the price**. Its worry about an odd-even leaf
artefact also dissolves: d = 3 and d = 4 are both flat, not alternating.

**Worlds strictly dominate depth at equal compute.** w = 128 d = 2 (530 ms/game) scores
0.7677 / 0.7403 against w = 32 d = 4 (1766 ms/game) at 0.7427 / 0.7170 -- better at both seats for a
third of the price -- and w = 64 d = 2 (271 ms) beats w = 32 d = 3 (482 ms). The practical setting is
therefore **64-128 worlds at depth 2**, with 32 the knee of the curve.

Paired at w = 32, d = 2 over 3,000 deals: **+9.73 +- 1.04 (z +9.3) at seat 0 and +4.57 +- 1.06
(z +4.3) at seat 1** -- both seats now past 3 sigma, which is what upgrades section 1's seat-1

noise (two-sided 0.6593 / 0.6710, response 0.7567 / 0.7167), as does the untouched Heuristic row

### What it cost

Run A 3 h 23 m, Run B 4 h 16 m, **7 h 39 m** against a 6-7 h estimate. The overrun is entirely
d = 4, budgeted at 8x depth 2 from 9.5d's *two-sided* measurements and actually 13.5x. Pairing

powered run; the sweep's own printed header claimed that split and has been corrected.

## 4. Checks

The continuation axis is pinned by four new tests, two of which exist because the obvious check was
**vacuous**:

- `response_value` equals a plain reference expectimax, and is **never below** `search_value` on the
  same state (a minimum over the opponent's children cannot exceed an expectation over them) -- an
  inequality that cannot come out of running the same code twice, and which catches a seat or sign
  error immediately.
- `test_the_continuation_rule_changes_what_the_agent_plays`: the two continuations, given the same
  name and seed so they draw *identical* worlds, must disagree on a measurable share of decisions.
- `test_the_response_agent_matches_the_exact_value_on_the_toy_that_separates_the_two_rules`: the
  first closure test written for this step used `TOY`, where the two continuations sit **0.22 /
  0.50 score points apart** against ~3.2 points of sampling noise at 200 games -- it passed, and it
  would have passed unchanged with the wrong continuation wired in. `TOY_FULL` separates them by
  **7-9 points** (n = 4, prior, vs Random seat 0: 0.7158 two-sided against 0.7870 responding), so
  the test moved there and now asserts both that the sampled agent matches exact `response` and
  that it is nearer that than exact `minimax`.

## 6. What is left on the table

Step 9.5d listed three untested approximations. This step closed the first (the continuation rule)
and the wiring defect beside it, and section 3 settled the budget questions. The rest, largest first:

1. **Inference, deliberately deferred.** `determinize_l1` still splits the unseen cards uniformly,
   so the agent uses the `prior` belief and does no opponent modelling. Two things argue against
   doing it here rather than for it: the toys measure `posterior` over `prior` at **0.0-0.6 points
   against Random**, which is the headline column, reaching 2.6 only against the Heuristic; and the
   belief is not cheaply available. A world's likelihood needs the opponent's hand *at each past
   decision*, which the current-hand determinization cannot reconstruct across the opponent's draws
   (the drawn card is unknown). Doing it properly means sampling the opponent's initial hand and the
   pile at the deal, replaying the recorded history weighting each particle by the opponent's action
   probabilities, and resampling per step -- **the "particle filter + expectimax" named in
   [plan.md](../../history/original-plan.md)'s original design for sampled L1/L2, and the only part of that design still
   unbuilt.** It is therefore scheduled as plan row **9.5f**, not merely deferred: PIMC itself was
   always meant to come with a belief, and 9.5d / 9.5e built it with a uniform determinization
   instead. The toys already hold its exact target, `uno.compiled.pimc`'s `"posterior"` weighting.
   A cheap trailing-likelihood approximation (weight by the opponent's probability over its trailing
   run of *play* events, stopping at the first draw) is available if the vs-Heuristic column needs
   something sooner, but it approximates the belief rather than computing it.

   **Settled in [step 9.5f](09.5f-results.md), which refuted the design this paragraph proposes.**
   The particle filter does not work: a particle survives an observed play only if it holds the
   played card (~7/98), so 64 of them decay 0.156 -> 0 over the opponent's first five plays, and
   the version built to that description scored *worse than the uniform prior it replaced*. The
   trailing-likelihood idea above is close to what shipped as the `window` rung, and this
   paragraph's caveat about it was right -- it is a *windowed* posterior, not the belief. But the
   hard constraints alone (`voids`: a draw proves the drawer held nothing playable, no opponent
   policy needed) carry the whole measured gain, **+2.83 / +4.40** points against Random at both
   seats, where the toy figure quoted here predicted 0.0-0.6.
2. **The leaf value function, now the binding constraint and the top of this list.** It is 9.5c's
   network, fitted on rulebot games, scoring outcome R^2 0.07-0.25 on these. Section 3 promoted it
   from "likeliest reason" to the residual explanation: with the continuation fixed and the seat
   networks fixed, the world ladder *still* flattens past 32, so what limits the agent is the
   quality of the evaluation each extra world receives, not the number of worlds. Fitting a network
   on-profile (on response-PIMC games) is the obvious next experiment, with the caveat 9.5c
   established that outcome R^2 orders value functions poorly.
3. **The world ladder was re-measured and is flat past 32** (section 3), so "32 worlds is enough"
   now carries forward with evidence rather than as an assumption -- though 64-128 is the better
   setting on the point estimates, and the ceiling is the leaf, not the budget. What remains untested
   is whether the ladder *un*-flattens once the leaf is on-profile, which is the natural pairing with
   item 2 and the reason not to treat 32 as permanent.
4. **D2 still grades against a two-sided reference search.** 9.5d showed the decomposition is
   sensitive to reference quality (a w = 8 reference produced negative components and a 112 % share);
   the response continuation is a better reference at the same cost.
5. **The response row is opponent-specific.** It needs the column's exact policy, so it is a ladder
   instrument rather than a player. A general full-UNO PIMC still has to use the two-sided rule, or
   an opponent model, and the 10-point gap measured here is what that generality costs.
