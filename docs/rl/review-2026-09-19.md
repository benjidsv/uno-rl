# RL phase second-opinion review — 2026-09-19

Review of commit `7368bd9` plus the existing working-tree evidence fix and
extended-budget changes. This is an audit, not a new experiment or a change to
the research direction. No training code or running experiment was modified.

**Assessment:** the complete-episode PPO implementation has substantial positive
correctness evidence. I did not find a demonstrated return-sign, own-turn,
baseline-detachment, or game-weighting error explaining the full-UNO plateau.
However, the claim that the learning gates passed is not supported by the saved
results; the evidence fix loses more information than its description says; and
checkpoint loading can silently change an old policy. B's superiority is still
an untested hypothesis, not an expected consequence of adding information.

## Resolution, later 2026-09-19

## Prioritized findings

### 1. P1 — the phase status overstates the toy learning validation

`docs/rl/README.md:4` says stages 1–5 acceptance checks pass. The canonical
Stage 5 result file still has TBD results. The actual saved artifact,
`logs/rl_toy/rl_toy_all_1789764834.json`, records:

- All four gradient checks passed; worst projection |z| = 2.162, largest
  PPO/reference relative error = 3.66e-6.
- Heuristic tabular gate: all five seeds pass at both seats.
- Random tabular gate: **only three of five seeds pass at both seats**.
  Seat 1 gaps for seeds 0 and 1 are 0.006243 and 0.008901, exceeding the
  predeclared 0.005 tolerance. These are exact game values, not sampling noise.
- Neural comparisons were run, but no quantitative neural acceptance threshold
  was used. `stage5-toy-gates.md` explicitly removes that threshold, contrary to
  `pipeline-plan.md:597–603`, which says to remain in diagnostics if one cannot
  be justified.
- The recorded learning study covers TOY only; I found no corresponding saved
  learning-gate evidence for the planned TOY_FULL / TOY2_SKIP progression.
  Mechanics tests on those rulesets are useful but are a different check.

The neural sampled BR gaps span approximately 1.77–6.42 score points across the
recorded cells/seeds. The exact-gradient comparator often does worse; e.g. all
five random seat-1 exact runs have a roughly 11.56-point BR gap. It therefore
does not provide a strong achieved optimization reference or a representation
ceiling. Passing gradient checks and failing learning gates can coexist.

**Recommendation:** reconcile the status/result documents and explicitly review
the residual toy failures before claiming the phase gate is complete. Preserve
the frozen failures; do not retroactively loosen their threshold. The current
full-UNO run remains a useful diagnostic.

### 2. P1 — actor-only loading ignores feature-schema compatibility

`uno/rl/checkpoint.py:221–234` saves but never validates `actor_schema` when
loading an exported actor. Tensor shapes did not change with schema v2, so loading
the old B export succeeds and silently evaluates it with the new evidence logic.

Reproduced with the original B pilot's `final_actor.pt`: saved schema
`5c134ddc8381d87c`, current schema `fbe13d1d87edcb56`; `load_actor` accepts it.
The full training restore path does check schema, so this defect is specific to
actor export/re-evaluation. Previously saved evaluation tables are not thereby
invalidated; re-evaluating the old actor under current code is the problem.

**Recommendation:** reject incompatible exported schemas, or explicitly select
a versioned legacy extractor. Also validate the export format version. Never
silently reinterpret old B checkpoints in new A/B comparisons.

### 3. P2 — the overflow fix drops multiplicity and nearly all old boards

`Evidence.ages()` (`uno/rl/evidence.py:154–180`) now emits at most one item per
age bin. The overflow item is the **oldest** voluntary draw in the entire game,
not the most recent item older than five drawn cards. Every other overflow board
is discarded from the network input, even though it remains in `items`.

The docstring says the global channel still counts all overflow items. It does
not: `features.py:318–345` builds every evidence channel from `Counter(ev.ages())`.
In a controlled extractor probe, one versus three overflow items gave identical
tok/col/glob arrays, with overflow global value 0.00390625 in both cases.
This is also at odds with the original contract's retained overflow history.

The prior implementation used additive projections. The problem being addressed
was loss of joint identity under marginal aggregation, not memory corruption or
an overwritten tensor cell. Selecting one event avoids that ambiguity for the
retained event by deleting the other events. It is a representation change with
a trade-off, not an information-preserving correction.

The new test checks that exactly one overflow item survives, but does not check
the promised global count. Its prose alternates between “most recent” and
“oldest.” Its two histories differ in their first top card, which already changes
the old extractor's token totals; that pair does not demonstrate the original
feature collision. Reverting `ages()` makes an intermediate dictionary assertion
fail, so the test does detect the implementation change, but not the claimed
collision at the production-feature boundary.

**Recommendation:** agree on the intended bounded summary (including which old
event(s) survive and whether counts survive), update the contract, and test the
actual old-feature collision plus the intended retained distinctions. Do not
change the representation midway through the running diagnostic.

### 4. P2 — inverse-CDF rounding can select an illegal action

`uno/rl/policy.py:75–78` accumulates FP32 probabilities and forces the last array
entry's CDF to one, even if that entry is illegal. If legal probability mass sums
slightly below one, the numerical remainder is assigned to that illegal action.

Reproduction: logits `[0.01, 0, 0]`, mask `[True, True, False]`, the production
masked log-softmax, and uniform `nextafter(1, 0)` yield action 2. The computed
probability mass is 0.99999994. This is a rare but real support violation.
Collection checks legality and raises; panel evaluation applies actions with
`check=False`. It is not evidence for a systematic several-point score deficit.

**Recommendation:** normalize and accumulate robustly, assign rounding remainder
only to a legal action, and test zero and near-one uniforms with trailing illegal
actions. Document any resulting random-stream trajectory changes.

### 5. P2 — selected-checkpoint reporting is incomplete across stop/resume

In `uno/rl/train.py`, scheduled evaluations update/save `best`, but initialization
and the final evaluation outside a scheduled boundary do not. The final summary
calls `select(run.eval_history)` including those points, so it can name a selected
policy that `best_actor.pt` does not contain. Resuming constructs an empty
`eval_history`, although `Progress.best_score` survives, so the final summary can
also ignore the better pre-resume checkpoint.

**Recommendation:** centralize evaluation/selection bookkeeping, preserve prior
selection history or its sufficient record, and ensure the reported selected
artifact exists. Final-checkpoint A/B comparisons are less exposed to this issue.

### 6. P2 — dirty-run provenance is not sufficient for reproduction

`uno/rl/track.py:69–97` records a base commit and `dirty: true`, but no patch
artifact or source-content hash. The plan explicitly requests a dirty patch
artifact. The current B run is dirty at `7368bd9`; the source difference is its
main experimental intervention. A future checkout of that commit cannot recreate
the run from its manifest alone.

**Recommendation:** retain the exact source diff and relevant untracked sources
at launch, alongside config and dependency identity. Do not replace this with a
commit requirement; commits remain Benji's decision.

## What the A/B results actually say

Snapshot of local CSVs during review:

| Policy | Decisions | Scheduled DEV score | Score SE |
|---|---:|---:|---:|
| Original B, schema 1 | 501,367 | 0.42871 | 0.01121 |
| A, schema 1 | 506,946 | 0.44824 | 0.01076 |
| Current B, schema 2 | 501,591 | 0.42529 | 0.01126 |

These are 256 deals/cell, with eight cells grouped by deal for uncertainty.
Current B's marginal nominal 95% half-width is about 0.0221. The current-minus-old
B point difference is -0.00342. Without retained paired per-deal outcomes, the
marginal SEs do not supply the paired-difference uncertainty. There is no measured
improvement attributable to the fix at this boundary, and no established plateau
or convergence claim either.

The high-precision historical A-minus-B result, +0.01276 with nominal CI
[+0.00879, +0.01672], remains evidence that those two particular old checkpoints
differ. It is not a five-seed arm effect, and it concerns the old B representation.

The new B at ~500k has roughly 20,000 completed games and 39 updates. Its decisions
are correlated within games, and forced-action rows provide no actor choice
gradient. “500k decisions” should not be read as 500k independent strategic labels.

Across the first 39 new-B updates through 513,940 decisions, mean pre-update critic
EV was 0.0650 and post-fit same-rollout EV 0.1325; the last values were 0.1037 and
0.1816. A's corresponding whole-run means were 0.0539 and 0.1260. This is modest
predictive signal, and post-fit EV is in-sample. Greater visual stability alone
does not show improved policy-gradient signal or better returns.

Actor norm clipping occurred on about 99.2% of new-B optimizer steps (mean of
per-update fractions); critic clipping on about 92.2%. Mean full-rollout sampled
KL was 0.0023, maximum 0.0121, and every observed update used four actor epochs.
Clipping is active, but frequent norm clipping does not establish a bug or prove
that raising the cap helps Adam. These are reasons for a controlled optimization
diagnostic after the representation protocol is resolved, not an arm-specific
retune during comparison.

## Why B need not win yet

- **Information versus learnability:** B includes A's inputs and could in
  principle ignore the additional channels. Finite-data optimization is not
  guaranteed to find that solution, much less profit from noisy history.
- **The new draw channels are very small.** With at most one event per bin,
  `count/8`, then `/4` for full-UNO token channels, `/8` for color channels, and
  `/32` for global totals yields maxima 0.03125, 0.015625, and 0.00390625.
  Many position indicators and last-play flags are 1. There is no normalization
  layer. This is an optimization hypothesis worth testing, not proof that the
  network ignores history. The fix also removes the formerly larger aggregate
  amplitudes when old events accumulated.
- **Credit assignment is indirect.** Terminal returns must teach both ordinary
  card tactics and how to interpret policy-dependent draw evidence. The league
  includes voluntary draws/keeps; a draw is not a hard void. How much incremental
  decision value this summary has on states reached by the learner is unmeasured.
- **Seed pairing is incomplete as an initialization control.** `Run.__post_init__`
  seeds once, builds the actor, then the critic. A/B actor projection widths differ,
  consuming different random draws. Same-seed A/B critics have different initial
  weights (reproduced). This does not invalidate a multi-seed algorithm comparison,
  but weakens a one-seed causal attribution to memory and makes EV comparisons
  particularly hard to interpret. Independent actor/critic initialization streams
  would make the intended control cleaner.
- **The critic changed with the fix.** CRITIC includes B's evidence for both
  actor arms. Comparing old A with new B changes critic feature semantics as well
  as actor arm. Both arms need the same resolved schema for the extended study.

I would not infer “more data is all B needs,” “B is useless,” or “A has hit its
representation ceiling” from the current evidence. A shared optimization or
basic tactical limitation could dominate a smaller benefit from public history.

## Positive implementation evidence and limits

Inspected the feature/evidence/layout/model path, collection and rollout assembly,
PPO, evaluation, manifests/streams, checkpointing/tracking, experiment entry points,
toy implementation/results, and parallel collection/recovery path.

The core design uses true complete episodes, fixed per-episode opponents, balanced
game quotas, learner-perspective terminal returns, pre-action detached critic
values frozen across PPO epochs, and T/G scaling for decision minibatches.
Consecutive own turns and after-draw decisions do not rely on seat alternation.
The critic is a separate L2 network, without pile-order input or shared actor
parameters. Masking and temperature are shared across inference/recomputation.
The equivariant grid and shared action scorer have meaningful symmetry tests;
the exact-gradient path is checked against finite differences and sampled games.
Evaluation groups the eight correlated cells by deal rather than pretending they
are independent. These are substantive strengths.

Secondary operational concerns from inspection: parallel timeout recovery retries
work without quarantining old workers/results, and its CPU fallback wraps the
coordinator actor directly (moving it to CPU if it was on an accelerator). That
path needs failure-injection validation before relying on parallel recovery;
the active single-process CPU run does not use it. The wall-budget predictor
omits evaluation/checkpoint cost. The new preset uses 7,500 seconds while the
Stage 8 document says 7,200; reconcile the manifest with the written protocol.

## Recommended next decisions

1. Let the current run finish as the declared diagnostic. Retain its current
   schema and source snapshot; do not splice another feature fix into it.
2. Resolve overflow semantics, schema-safe evaluation, and the inaccurate gate
   record before launching the remaining expensive A/B study.
3. Evaluate final policies with the correctly versioned extractor and the frozen
   direct paired panel. Compare current-schema A and B at matched budgets and
   multiple training seeds; keep game uncertainty distinct from seed variation.
4. Before a larger architecture change, agree on a bounded diagnostic that
   distinguishes use of history from general learning quality: quantify evidence
   occupancy/amplitudes on real reached states, measure policy sensitivity to
   removing the evidence block, and compare paired game scores. Input ablation
   is a sensitivity test under distribution shift, not a representation ceiling.
5. If both arms still underperform similarly, diagnose the shared optimizer,
   tactical behavior and critic before assuming history capacity is the main
   bottleneck. Any scaling, initialization, entropy or critic intervention should
   be a separately labeled experiment with unchanged opponent/evaluation streams.
